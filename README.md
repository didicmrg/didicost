# DIDICOST

Controle pessoal de gastos e renda do mês, feito para o iPhone.

- Lançamentos únicos, parcelados e fixos, com categorias que aprendem sozinhas
- Resumo do mês com roleta por categoria, limite e aviso
- Login com Google (Supabase): cada conta vê só os próprios dados
- Funciona offline e pode ser instalado na tela de início

Site estático: não tem etapa de build.
